# v0.1.1

This maintenance release adds GitHub Actions CI for the existing offline research package. The workflow runs on pushes to `main`, pull requests targeting `main`, and manual dispatch.

The Ubuntu 24.04 job uses Python 3.11, installs the package in editable mode with the `dev` extra, runs `pip check`, executes the full pytest suite without network access, and checks package imports in Python isolated mode.

The financial behavior from v0.1.0 is unchanged. This release adds no market-data or live-trading functionality.

The offline suite uses synthetic fixtures and establishes no empirical profitability. Ubuntu resolves dependencies independently of the Windows reference constraints. CI results apply to the Ubuntu and Python versions exercised by the job. [Windows reference constraints](../../constraints-windows-py311.txt)
